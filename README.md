# Exercism — JavaScript

Solutions for the **JavaScript Track** on Exercism.

## About

This repository contains my solutions to the JavaScript exercises from Exercism, covering **37 JavaScript concepts** through **159 coding exercises**.

The exercises focus on:

* JavaScript fundamentals and syntax
* Variables, constants, and data types
* Functions and higher-order functions
* Strings and arrays
* Objects and object-oriented programming
* Control flow and iteration
* Error handling
* Closures and scope
* Functional programming
* Asynchronous JavaScript
* Language-specific patterns and idiomatic JavaScript
* Problem solving and code organization

The track combines **Concept Exercises**, which introduce specific JavaScript concepts, with **Practice Exercises**, which reinforce those concepts through problem solving.
